4  Análisis Exploratorio de Datos

4.1 Preparación mínima para EDA

En este capítulo se aplica una preparación mínima orientada a visualización y descripción (no al modelado):

  • Normalizar release_date como fecha y derivar release_year.
  • Tratar owners como variable ordinal (intervalos).
  • Construir transformaciones log1p() solo para variables con colas largas (price, positive_ratings).
  • Resumir columnas multietiqueta (separadas por ;) mediante contadores simples.

4.2 Análisis univariado

4.2.1 Variables numéricas

A continuación se resume numéricamente el catálogo y se comentan fenómenos típicos en mercados digitales: asimetría, colas largas y exceso de ceros en algunas métricas agregadas.

Mostrar código 
q <- function(x, p) as.numeric(quantile(x, p, na.rm = TRUE))

num_stats <- tibble::tibble(
  variable = c("price", "positive_ratings", "negative_ratings", "average_playtime",
               "median_playtime", "achievements", "required_age"),
  n = c(sum(!is.na(steam$price)),
        sum(!is.na(steam$positive_ratings)),
        sum(!is.na(steam$negative_ratings)),
        sum(!is.na(steam$average_playtime)),
        sum(!is.na(steam$median_playtime)),
        sum(!is.na(steam$achievements)),
        sum(!is.na(steam$required_age))),
  p25 = c(q(steam$price, 0.25),
          q(steam$positive_ratings, 0.25),
          q(steam$negative_ratings, 0.25),
          q(steam$average_playtime, 0.25),
          q(steam$median_playtime, 0.25),
          q(steam$achievements, 0.25),
          q(steam$required_age, 0.25)),
  median = c(q(steam$price, 0.50),
             q(steam$positive_ratings, 0.50),
             q(steam$negative_ratings, 0.50),
             q(steam$average_playtime, 0.50),
             q(steam$median_playtime, 0.50),
             q(steam$achievements, 0.50),
             q(steam$required_age, 0.50)),
  p75 = c(q(steam$price, 0.75),
          q(steam$positive_ratings, 0.75),
          q(steam$negative_ratings, 0.75),
          q(steam$average_playtime, 0.75),
          q(steam$median_playtime, 0.75),
          q(steam$achievements, 0.75),
          q(steam$required_age, 0.75)),
  max = c(max(steam$price, na.rm = TRUE),
          max(steam$positive_ratings, na.rm = TRUE),
          max(steam$negative_ratings, na.rm = TRUE),
          max(steam$average_playtime, na.rm = TRUE),
          max(steam$median_playtime, na.rm = TRUE),
          max(steam$achievements, na.rm = TRUE),
          max(steam$required_age, na.rm = TRUE))
)

Observaciones principales:

  • Precio (price): presenta asimetría a la derecha y valores atípicos. Además, existe una fracción no despreciable de juegos gratuitos.

4.2.2 Variables categóricas

Se describen variables estructurales del catálogo: disponibilidad en inglés, intervalos de propietarios y combinaciones de plataformas.

prop_english <- mean(steam$english == 1, na.rm = TRUE)

owners_tab <- steam %>%
  count(owners, sort = TRUE) %>%
  mutate(pct = n / sum(n))

platforms_tab <- steam %>%
  count(platforms, sort = TRUE) %>%
  slice_head(n = 8) %>%
  mutate(pct = n / sum(n))

4.4 Análisis multivariado

Para detectar dependencias globales entre variables numéricas, se calcula la matriz de correlaciones (Pearson) y se visualiza como mapa de calor.

Mostrar código 
num_vars <- steam %>%
  transmute(
    price,
    achievements,
    n_genres,
    n_categories,
    n_tags,
    positive_ratings,
    negative_ratings,
    average_playtime,
    median_playtime
  )

cor_mat <- cor(num_vars, use = "pairwise.complete.obs")

cor_long <- as.data.frame(as.table(cor_mat)) %>%
  rename(var1 = Var1, var2 = Var2, cor = Freq)

ggplot(cor_long, aes(x = var1, y = var2, fill = cor)) +
  geom_tile() +
  scale_fill_gradient2(
    low = "#3B4CC0", mid = "white", high = "#B40426",
    midpoint = 0
  ) +
  coord_fixed() +
  labs(
    title = "Matriz de correlación (Pearson)",
    x = NULL, y = NULL
  ) +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))

Lectura típica en este dataset: positive_ratings y negative_ratings suelen estar fuertemente correlacionadas (juegos con gran exposición acumulan tanto valoraciones positivas como negativas). El resto de variables aporta señales más independientes.

4.5 Limitaciones y consideraciones de calidad

  • Variables multietiqueta (platforms, genres, categories, steamspy_tags) están codificadas como texto con separador ;. Para un análisis detallado por etiqueta sería necesaria una normalización (explosión a formato largo).
  • Owners es un intervalo categórico: útil como ordinal, pero limita análisis cuantitativos finos.
  • Exceso de ceros en playtime: average_playtime = 0 en ≈ 77.21% y median_playtime = 0 en ≈ 77.21%.
  • Outliers: existen precios y recuentos de valoraciones extremos; en capítulos posteriores se justifica el uso de transformaciones logarítmicas.
  • Agregación: el dataset está a nivel de juego; no permite inferencia de preferencias/uso a nivel de usuario.

4.6 Conclusión del EDA

El catálogo presenta alta concentración de popularidad (colas largas en valoraciones) y una estructura de precios asimétrica con una fracción de juegos gratuitos (≈ 9.46%). Variables como precio, soporte multiplataforma y metadatos de catálogo muestran patrones descriptivos plausibles y motivan el modelado supervisado de los capítulos siguientes.
